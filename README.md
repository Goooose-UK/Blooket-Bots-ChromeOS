                                                Blooket Bot-ter


A standalone webpage with a Blooket-themed name generator, selectable themes, and a fruit merge game.
Features for ChromeOS... No one can stop the Bot Waves HAHAHAHAHAHAHHAHAHAHA
                                         
                                                  Game Link
                               https://waterfowl-studio.github.io/Blooket-Bots-ChromeOS/
 
Generate a random name and Blooket join link from a game code.
Copy the generated name.
Play a physics-style fruit merge game.
Choose Light, Dark, or Pastel themes.
Runs in a browser without installing libraries or dependencies.

To Run it open https://waterfowl-studio.github.io/Blooket-Bots-ChromeOS/ in your browser :D Thats it!
